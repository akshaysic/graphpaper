# Reveal

Rises content 24px and fades it in the first time it scrolls into view.

**You provide** children, and `root` when the scrolling element is not the window.

Opacity over `dur-slow` with `ease-out-quad`, movement with `ease-out-cubic`. Content already on screen is never hidden, and nothing is hidden before JavaScript runs. Plain under reduced motion. Use it on images and cards in long sections, never on headlines.
