# ArrowButton

A 40px outlined square with one arrow glyph, used to page a CardRail.

**You provide** `direction` (`prev` or `next`), `onClick`, and a specific `label` such as "Next workflow".

Border `ink`, corners `radius-m`, glyph in `intro`. Hover fills `surface`; press scales to 0.95 over `dur-fast` (dropped under reduced motion). Always used as a pair.
